## 功能

- 统计三种等级（绿／紫／金）的礼物，并标记最爱礼物。
- 从内置的里程碑列表选择奖励目标，也可自定义目标和最终目标。
- 可创建多个组合方案，每个方案有各自的礼物平衡规则。
- 从当前好感度开始规划：自动估算已用掉的礼物，只计算剩余的里程碑。
- 结果：精准命中、超额、不足、每阶段所需礼物、差距图和进度条。
- 可用截图配合 AI 辅助填写、保存／载入数据、18 种语言、浅色／深色模式和 11 种主题色。

## 使用方法

1. **礼物**：输入每种礼物的数量，点星标记最爱。
2. **目标**：输入当前好感度（可不填），勾选想要的奖励列表。
3. **组合**：使用默认值，或打开“高级设置”调整。
4. **结果**：查看每种礼物该用多少。

## 在本地运行

- 下载 `download/combo_calculator_single.html`，双击打开。
- 或下载整个项目，保持 `css`、`js`、`lang` 文件夹在 `index.html` 旁，再打开 `index.html`。

## 部署到 GitHub Pages

1. 把文件夹内的**所有内容**上传到仓库根目录（保留文件夹结构）。
2. 进入 **Settings → Pages**，选择 main 分支和根目录。
3. 更新后请强制刷新（Ctrl/Cmd + Shift + R）。
