## المزايا

- عدّاد للهدايا من ثلاث فئات (أخضر / بنفسجي / ذهبي) مع تحديد المفضلة.
- أهداف المكافآت: قوائم مراحل مدمجة، وأهداف مخصصة، وهدف نهائي.
- عدة تشكيلات (خطط)، لكل منها قاعدة توازن خاصة: أي لون أكثر، وفرق يُبقى **ضمن نطاق** (مع إعدادات سريعة مثل 0–25 أو 0–200)، أو **أكبر** ما يمكن، أو **أصغر** ما يمكن.
- التخطيط من التقارب الحالي: يقدّر الهدايا المستخدمة ويحسب المراحل المتبقية فقط.
- النتائج: الإصابات الدقيقة والزيادة والنقص لكل مرحلة، والهدايا المطلوبة لكل مرحلة (مع أيقونات الهدايا المستخدمة)، ومخطط الفرق وأشرطة التقدم. لا تتغير النتائج إلا عند الضغط على **حساب كل التشكيلات**، وينبّهك شريط علوي عندما تصبح قديمة.
- خيارات متقدمة (مخفية افتراضيًا): نقطة بدء حد الفرق، وحد «أقصى نقاط فوق الهدف»، والهدايا غير المفضلة، وحد إجمالي لكل لون، وحدود لكل هدية (مع مسحها كلها بلمسة واحدة)، وترتيب إنفاق مخصص.
- التعبئة بمساعدة الذكاء الاصطناعي: انسخ الموجّه وأرسله مع لقطة شاشة إلى دردشة ذكاء اصطناعي **جديدة**، ثم الصق رد JSON (أو استورده من ملف). قد يخطئ الذكاء الاصطناعي في قراءة الأرقام، فقارنها دائمًا باللعبة. كما تتوفر خاصية حفظ/تحميل البيانات و18 لغة والوضع الفاتح/الداكن و11 سمة ألوان.

## طريقة الاستخدام

1. **الهدايا**: أدخل عدد كل هدية وعلّم المفضلة بالنجمة.
2. **الأهداف**: أدخل التقارب الحالي (اختياري) وحدّد قوائم المكافآت المطلوبة.
3. **التركيبات**: أبقِ الإعدادات الافتراضية أو اختر قاعدة الفرق (نطاق أو أكبر أو أصغر) وافتح *الإعدادات المتقدمة*.
4. **النتائج**: اضغط **حساب كل التشكيلات** ثم اقرأ عدد كل نوع من الهدايا المطلوب استخدامه.

## التشغيل محليًا

- نزّل `download/combo_calculator_single.html` وانقر عليه نقرًا مزدوجًا.
- أو نزّل المستودع كاملًا، وأبقِ المجلدات `css` و`js` و`lang` بجانب `index.html`، ثم افتح `index.html`.

## النشر على GitHub Pages

1. ارفع **كل محتويات** المجلد إلى جذر المستودع (مع الحفاظ على بنية المجلدات).
2. من **Settings → Pages** اختر الفرع main والمجلد الجذر.
3. بعد التحديث، أعد تحميل الصفحة بالقوة (Ctrl/Cmd + Shift + R).
