## ฟีเจอร์

- นับของขวัญสามระดับ (เขียว / ม่วง / ทอง) และกำหนดของโปรด
- เลือกเป้าหมายรางวัลจากรายการไมล์สโตนในตัว หรือเพิ่มเป้าหมายเองและเป้าหมายสุดท้าย
- สร้างคอมโบ (แผน) ได้หลายแบบ แต่ละแบบมีกฎสมดุลของขวัญของตัวเอง
- วางแผนจากค่าความสนิทปัจจุบัน: ประมาณของขวัญที่ใช้ไปแล้ว และคำนวณเฉพาะไมล์สโตนที่เหลือ
- ผลลัพธ์: ตรงเป๊ะ ส่วนเกิน ส่วนขาด ของขวัญที่ต้องใช้ในแต่ละขั้น กราฟส่วนต่าง และแถบความคืบหน้า
- ช่วยกรอกด้วย AI จากภาพหน้าจอ บันทึก/โหลดข้อมูล 18 ภาษา โหมดสว่าง/มืด และธีมสี 11 แบบ

## วิธีใช้

1. **ของขวัญ**: ใส่จำนวนของขวัญแต่ละชนิด และกดดาวเพื่อเลือกของโปรด
2. **เป้าหมาย**: ใส่ค่าความสนิทปัจจุบัน (ไม่บังคับ) แล้วติ๊กรายการรางวัลที่ต้องการ
3. **คอมโบ**: ใช้ค่าเริ่มต้น หรือเปิด *การตั้งค่าขั้นสูง*
4. **ผลลัพธ์**: ดูว่าต้องใช้ของขวัญแต่ละชนิดกี่ชิ้น

## รันในเครื่อง

- ดาวน์โหลด `download/combo_calculator_single.html` แล้วดับเบิลคลิก
- หรือดาวน์โหลดทั้งโปรเจกต์ โดยเก็บโฟลเดอร์ `css`, `js`, `lang` ไว้ข้าง `index.html` แล้วเปิด `index.html`

## เผยแพร่บน GitHub Pages

1. อัปโหลด**เนื้อหาทั้งหมด**ในโฟลเดอร์ไปที่ root ของรีโพซิทอรี (คงโครงสร้างโฟลเดอร์)
2. ไปที่ **Settings → Pages** แล้วเลือกสาขา main และโฟลเดอร์ root
3. หลังอัปเดต ให้รีโหลดแบบบังคับ (Ctrl/Cmd + Shift + R)
