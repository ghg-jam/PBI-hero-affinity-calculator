## ฟีเจอร์

- นับของขวัญสามระดับ (เขียว / ม่วง / ทอง) และกำหนดของโปรด
- เลือกเป้าหมายรางวัลจากรายการไมล์สโตนในตัว หรือเพิ่มเป้าหมายเองและเป้าหมายสุดท้าย
- หลายคอมโบ (แผน) แต่ละคอมโบมีกฎความสมดุลของของขวัญเอง: สีไหนมากกว่า และส่วนต่างให้อยู่**ในช่วง** (มีค่าตั้งไว้ให้ เช่น 0–25, 0–200) **มากที่สุด**เท่าที่ทำได้ หรือ**น้อยที่สุด**เท่าที่ทำได้
- วางแผนจากค่าความสนิทปัจจุบัน: ประมาณของขวัญที่ใช้ไปแล้ว และคำนวณเฉพาะไมล์สโตนที่เหลือ
- ผลลัพธ์: จำนวนที่ตรงเป๊ะ ส่วนเกินและส่วนขาดของแต่ละเป้าหมาย ของขวัญที่ต้องใช้ในแต่ละช่วง (พร้อมไอคอนของขวัญที่ใช้) กราฟส่วนต่าง และแถบความคืบหน้า ผลลัพธ์จะเปลี่ยนเมื่อกด **คำนวณทุกคอมโบ** เท่านั้น และจะมีแถบแจ้งเมื่อผลลัพธ์ไม่เป็นปัจจุบัน
- ตัวเลือกขั้นสูง (ซ่อนไว้เป็นค่าเริ่มต้น): จุดเริ่มของขีดจำกัดส่วนต่าง ขีดจำกัด “แต้มเกินเป้าหมายสูงสุด” ของขวัญที่ไม่ใช่ของโปรด ขีดจำกัดรวมต่อสี ขีดจำกัดต่อของขวัญ (ล้างทั้งหมดได้ในครั้งเดียว) และลำดับการใช้ที่กำหนดเอง
- ช่วยกรอกด้วย AI: คัดลอกพรอมต์ ส่งพร้อมภาพหน้าจอไปยังแชท AI **ใหม่** แล้ววางคำตอบ JSON (หรือนำเข้าจากไฟล์) AI อาจอ่านตัวเลขผิด ควรเทียบกับในเกมเสมอ รองรับการบันทึก/โหลดข้อมูล 18 ภาษา โหมดสว่าง/มืด และธีมสี 11 แบบ

## วิธีใช้

1. **ของขวัญ**: ใส่จำนวนของขวัญแต่ละชนิด และกดดาวเพื่อเลือกของโปรด
2. **เป้าหมาย**: ใส่ค่าความสนิทปัจจุบัน (ไม่บังคับ) แล้วติ๊กรายการรางวัลที่ต้องการ
3. **คอมโบ**: ใช้ค่าเริ่มต้น หรือเลือกกฎส่วนต่าง (ช่วง มากที่สุด หรือน้อยที่สุด) แล้วเปิด *การตั้งค่าขั้นสูง*
4. **ผลลัพธ์**: กด **คำนวณทุกคอมโบ** แล้วดูว่าต้องใช้ของขวัญแต่ละชนิดเท่าไร

## รันในเครื่อง

- ดาวน์โหลด `download/combo_calculator_single.html` แล้วดับเบิลคลิก
- หรือดาวน์โหลดทั้งโปรเจกต์ โดยเก็บโฟลเดอร์ `css`, `js`, `lang` ไว้ข้าง `index.html` แล้วเปิด `index.html`

## เผยแพร่บน GitHub Pages

1. อัปโหลด**เนื้อหาทั้งหมด**ในโฟลเดอร์ไปที่ root ของรีโพซิทอรี (คงโครงสร้างโฟลเดอร์)
2. ไปที่ **Settings → Pages** แล้วเลือกสาขา main และโฟลเดอร์ root
3. หลังอัปเดต ให้รีโหลดแบบบังคับ (Ctrl/Cmd + Shift + R)
