‘Pixel Brave Idle’을 위한 무료 웹 계산기입니다. 보유한 선물을 입력하고 목표 호감도 보상을 고르면, 각 선물이 최소 몇 개 필요한지 계산해 줍니다.

모든 계산이 브라우저 안에서 이루어집니다. 계정도 서버도 필요 없고 데이터는 업로드되지 않습니다.

**온라인에서 사용:** https://ghg-jam.github.io/PBI-hero-affinity-calculator/

## 주요 기능

- 세 가지 등급(초록/보라/금색) 선물을 관리하고 즐겨찾기를 지정합니다.
- 내장된 마일스톤 목록에서 보상 목표를 고르거나 직접 목표와 최종 목표를 추가합니다.
- 여러 콤보(계획)를 만들 수 있으며, 각각 선물 균형 규칙을 따로 설정합니다.
- 현재 호감도부터 계획: 이미 사용한 선물을 추정하고 남은 마일스톤만 계산합니다.
- 결과: 정확히 달성, 초과, 부족, 단계별 필요한 선물, 격차 차트, 진행 막대.
- 스크린샷 기반 AI 입력 도우미, 데이터 저장/불러오기, 18개 언어, 라이트/다크 모드, 11가지 테마 색상.

## 사용 방법

1. **선물**: 각 선물의 보유 수량을 입력하고 별로 즐겨찾기를 표시합니다.
2. **목표**: 현재 호감도(선택)를 입력하고 원하는 보상 목록을 체크합니다.
3. **콤보**: 기본값을 쓰거나 ‘고급 설정’에서 조정합니다.
4. **결과**: 각 선물을 얼마나 써야 하는지 확인합니다.

## 로컬에서 실행

- `download/combo_calculator_single.html`을 다운로드해 더블클릭합니다.
- 또는 저장소 전체를 다운로드하고 `css`, `js`, `lang` 폴더를 `index.html` 옆에 둔 채 `index.html`을 엽니다.

## GitHub Pages에 배포

1. 폴더 안의 **모든 내용**을 저장소 루트에 업로드합니다(폴더 구조 유지).
2. **Settings → Pages**에서 main 브랜치와 루트 폴더를 선택합니다.
3. 업데이트 후에는 강제 새로고침(Ctrl/Cmd + Shift + R)을 하세요.
