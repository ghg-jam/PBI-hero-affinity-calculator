Бесплатный веб-калькулятор для **Pixel Brave Idle**: введите имеющиеся подарки, выберите награды за уровень привязанности — и узнайте, сколько подарков каждого вида нужно как минимум.

Работает полностью в браузере. Без аккаунта и сервера, ничего не загружается.

**Открыть онлайн:** https://ghg-jam.github.io/PBI-hero-affinity-calculator/

> Неофициальный инструмент от фанатов. Не связан с разработчиком игры и не одобрен им.

## Возможности

- Счётчик подарков трёх уровней (зелёные / фиолетовые / золотые) с избранными.
- Цели наград: встроенные списки этапов, свои цели и итоговая цель.
- Несколько комбо (планов), у каждого своё правило баланса: какого цвета больше и разница, которая держится **в диапазоне** (есть быстрые пресеты вроде 0–25 или 0–200), **как можно больше** или **как можно меньше**.
- План от текущей привязанности: оценивает уже потраченные подарки и считает только оставшиеся этапы.
- Результаты: точные попадания, избыток и нехватка по каждой отметке, подарки для каждого этапа (с иконками использованных подарков), график разницы и полосы прогресса. Результаты меняются только после нажатия **«Рассчитать все комбо»**, а полоса сверху сообщает, что они устарели.
- Расширенные настройки (по умолчанию скрыты): с какой отметки действует ограничение разницы, лимит «максимум очков сверх цели», неизбранные подарки, общий лимит по цвету, лимиты по подаркам (с очисткой всех одним нажатием) и свой порядок расходования.
- Заполнение с ИИ: скопируйте промпт, отправьте со скриншотом в **новый** чат с ИИ и вставьте JSON-ответ (или импортируйте из файла). ИИ может неверно прочитать числа — всегда сверяйте с игрой. Также: сохранение/загрузка данных, 18 языков, светлая/тёмная тема и 11 цветовых тем.

## Как пользоваться

1. **Подарки**: введите количество каждого и отметьте избранный звёздочкой.
2. **Цели**: укажите текущую привязанность (необязательно) и отметьте нужные списки наград.
3. **Комбо**: оставьте значения по умолчанию или выберите правило разницы (диапазон, наибольшая или наименьшая) и откройте *Расширенные настройки*.
4. **Результаты**: нажмите **«Рассчитать все комбо»** и посмотрите, сколько каких подарков использовать.

## Запуск локально

- Скачайте `download/combo_calculator_single.html` и дважды щёлкните по нему.
- Или скачайте весь репозиторий, оставьте папки `css`, `js` и `lang` рядом с `index.html` и откройте `index.html`.

## Публикация на GitHub Pages

1. Загрузите **всё содержимое** папки в корень репозитория (сохраняя структуру папок).
2. В **Settings → Pages** выберите ветку main и корневую папку.
3. После обновления выполните жёсткое обновление страницы (Ctrl/Cmd + Shift + R).
