『Pixel Brave Idle』向けの無料Web計算機。持っているギフトを入力し、目標の好感度報酬を選ぶと、各ギフトが最低いくつ必要かを計算します。

すべてブラウザ内で動作します。アカウントもサーバーも不要で、データは送信されません。

**オンラインで使う:** https://ghg-jam.github.io/PBI-hero-affinity-calculator/

## 主な機能

- 3段階（緑／紫／金）のギフトを管理し、お気に入りを設定。
- 内蔵のマイルストーン一覧から報酬目標を選択。独自の目標や最終目標も設定可能。
- 複数のコンボ（プラン）。それぞれに色ごとのバランスルールを設定でき、差分は**範囲内**に収める（0–25・0–200などのクイックプリセット付き）、できるだけ**大きく**、またはできるだけ**小さく**から選べます。
- 現在の好感度から計画：使用済みギフトを推定し、残りのマイルストーンだけを計算。
- 結果：各マイルストーンのぴったり達成・超過・不足、各段階に必要なギフト（使用ギフトのアイコン付き）、差分グラフ、進捗バー。結果は「全コンボを計算」を押したときだけ更新され、古くなると上部のバーでお知らせします。
- 詳細設定（初期は非表示）：差分制限の開始位置、「目標超過の上限」、お気に入り以外のギフト、色ごとの合計上限、ギフトごとの上限（ワンタップでクリア可能）、使用順のカスタマイズ。
- AIによる入力補助：プロンプトをコピーし、スクリーンショットと一緒に**新しい**AIチャットへ送り、返ってきたJSONを貼り付け（またはファイルから読み込み）。AIは数字を読み間違えることがあるので、必ずゲームと見比べてください。データの保存／読み込み、18言語、ライト／ダークモード、11色のテーマにも対応。

## 使い方

1. **ギフト**：各ギフトの所持数を入力し、星でお気に入りを選択。
2. **目標**：現在の好感度（任意）を入力し、使いたい報酬リストにチェック。
3. **コンボ**：初期設定のままか、差分ルール（範囲・最大・最小）を選び、「詳細設定」を開きます。
4. **結果**：「全コンボを計算」を押して、各ギフトの使用数を確認します。

## ローカルで実行

- `download/combo_calculator_single.html` をダウンロードしてダブルクリック。
- またはリポジトリ全体をダウンロードし、`css`・`js`・`lang` フォルダを `index.html` の隣に置いて `index.html` を開く。

## GitHub Pages に公開

1. フォルダ内の**すべて**をリポジトリのルートにアップロード（フォルダ構成を維持）。
2. **Settings → Pages** で main ブランチとルートを選択。
3. 更新後は強制再読み込み（Ctrl/Cmd + Shift + R）。
